# 泰院 AI 学长

> 泰山学院新生的 24 小时校园问答助手 —— AI 答 + 人工兜底
> 发起人：梁斌 ｜ 发起日期：2026-08-13

## 一句话定位

新生问报到的任何问题，3 秒内得到准确回答；AI 答不了的，转给学长学姐人工答。

## 为什么做（需求洞察）

泰山学院每年 9 月迎来新生，开学季有大量重复问题：

- 报到流程是什么？宿舍怎么分？被褥要不要带？
- 选课怎么选？体育课抢不到怎么办？
- 教材费怎么交？助学贷款怎么办？

现状：新生只能在 QQ 群/贴吧问学长学姐 → 答不过来、回复慢、重复回答同一个问题。信息散落在学校官网、新生手册、老生经验里，没有人整理。

**机会**：2026 级新生 9 月初入学 = 真实需求窗口 + 我就在现场能找到真实用户。

## 目标用户

- 首批：泰山学院 2026 级新生
- 后续：大二-大四学生（选课、考试、实习等场景）

## MVP 功能（v0.1，2026-08-16 上线）

1. **校园知识问答**：30–50 条高频问题知识库（报到/宿舍/食堂/选课/考试政策），来源为学校官网 + 新生手册 + 老生经验
2. **多轮对话上下文**：追问"那需要带多少钱"能接住上一句的语境
3. **诚实兜底**：不知道就明确说不知道，并引导转人工（防幻觉是产品底线）

**明确不做**（v0.1）：账号系统、多校园、群机器人接入、复杂工具调用

## 技术方案

- 模型：腾讯混元大模型 hy3，OpenAI 兼容接口（tokenhub.tencentmaas.com/v1/chat/completions）（选混元的原因：① 目标团队产品线，深度使用 ② 有免费额度）
- 架构：Python + 知识检索（先做关键词匹配 FAQ，跑通后升级 RAG 向量检索）+ 网页聊天界面
- 已就绪：`app/chat.py` 骨架（对话循环 + .env 配置），2026-08-13 调通
- 已知问题：模型对泰山学院的回答是"通用常识 + 合理编造"，不知道本校具体规定——FAQ 知识库就是用来解决这个幻觉问题的
- Memory：会话上下文管理（短期）+ 高频问题沉淀（长期，v2）

## 核心指标

| 指标 | 目标 |
|---|---|
| 使用用户数 | ≥ 30 |
| 提问数 | ≥ 100 |
| 回答满意率（用户自评） | ≥ 70% |
| 未解决率（兜底/答错） | < 30% |

## 迭代时间线

- 8.19–8.27：v1.1 → v2 迭代（记忆、工具能力、按反馈改）
